AirTouch lets you control a Windows PC with hand gestures through a regular webcam: move the
cursor, click, drag, scroll and type on the Windows on-screen keyboard — without a mouse or
keyboard. Everything runs locally; video never leaves your computer and nothing is saved.

## Download

`AirTouch.exe` — single file, no installation, works offline.

SHA256: `6CE504AFBC5EF20EAC973CAE6B1A5D9B1FC9340FDA91B37B568414D87C8A1B57`

## Requirements

- Windows 10 or 11, any regular webcam
- Normal room lighting, hand 0.3–1 m from the camera; either hand works

## Gestures

| Action             | Gesture                                                                 |
|--------------------|-------------------------------------------------------------------------|
| Move cursor        | **L pose**: index + thumb straight, other fingers folded                 |
| Left click         | from L, bend the thumb in and straighten it again                        |
| Double click       | two quick thumb bends                                                    |
| Drag               | keep the thumb bent until `DRAG READY`, move the hand, straighten to drop |
| Right click        | from L, bend the index finger and straighten it again                    |
| Scroll             | index + middle together, thumb tucked; hold the hand above / below the start point |
| Pause / resume     | hold a fist ~1 s                                                         |
| On-screen keyboard | hold a shaka 🤙 (only thumb + pinky out) ~1 s                             |
| Rest               | any other pose — the cursor stays where it is                            |

**Ctrl+Alt+G** turns gesture control off and on instantly, so the real mouse can always take over.

## Features

- Tray icon colored by state (on / paused / off / error); left click toggles control
- Small always-on-top indicator: is the hand seen, which gesture, last action
- **Calibration** (tray → Calibrate...): adapts cursor speed to the area that is comfortable
  for your hand and smoothing to your hand tremor
- **Settings** (tray → Settings...): cursor speed, aiming, smoothness, hold times, scroll speed,
  camera — saved to `%APPDATA%\AirTouch\settings.json`
- Own gesture classifier (MLP on MediaPipe hand landmarks), 99.6% accuracy on the held-out set
- Pointer acceleration: slow moves for precise aiming, quick moves to cross the screen

## First start

1. **SmartScreen:** the exe is not code-signed, so Windows may show "Windows protected your
   PC" — click **More info** → **Run anyway**.
2. **UAC prompt:** AirTouch asks for administrator rights. Windows blocks input to the
   on-screen keyboard (`osk.exe`) from normal programs, and this also lets AirTouch click
   windows that run as administrator. Without it, everything except the keyboard works
   (`AirTouch.exe --no-admin`).
3. Raise your hand into the camera view, show the L pose and move.
4. Optional: tray → **Calibrate...** for a cursor speed that fits your hand.

Some antivirus programs flag one-file PyInstaller apps by mistake; the source is in this
repository and the build is reproducible with `python -m scripts.build`.

## Known limitations

- Typing on the on-screen keyboard is slow at first (4.3 words per minute measured on a first
  attempt); it improves with practice.
- One hand at a time; very dim light or a hand partly out of the frame makes tracking unstable.
