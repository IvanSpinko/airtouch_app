AirTouch 1.1.0 adds its own on-screen keyboard designed for gestures. It replaces the Windows
on-screen keyboard (`osk.exe`) by default, types faster with less aiming, and no longer needs
administrator rights.

## Download

`AirTouch.exe` — single file, no installation, works offline.

SHA256: `DAA68765DDF8B6D6BDA7044BEB0A242184F5D99C613DE526FB2DAF48FEE2F6A9`

## What's new

- **AirTouch keyboard.** Hold a shaka 🤙 ~1 s to open or close it. It stays on top at the
  bottom of the screen and never takes the keyboard focus, so text goes to the app you are
  working in.
- **Cursor snapping.** Over the keyboard the cursor snaps to the center of the nearest key
  and only moves to a neighbouring key when clearly closer to it. Bend the thumb (same as a
  left click) to press the highlighted key.
- **English and Russian layouts** built into the keyboard; the language key switches them.
  Characters are sent as Unicode, so the Windows input language does not matter.
- **Word suggestions:** a row of 3 words for the word being typed; choosing one inserts the
  word and a space.
- **Move the keyboard:** hover the grip bar at the top edge, keep the thumb bent until
  `MOVE KEYBOARD`, move the hand, straighten the thumb to place it. The real mouse can drag
  the grip bar too.
- **No UAC prompt** with the AirTouch keyboard. Administrator rights are only requested when
  `osk.exe` is chosen in tray → Settings... ("AirTouch keyboard" off).
- The status indicator is now also shown in the command-line mode with the camera window
  (`python -m gesture_control.main`).

## Gestures

| Action             | Gesture                                                                 |
|--------------------|-------------------------------------------------------------------------|
| Move cursor        | **L pose**: index + thumb straight, other fingers folded                 |
| Left click / press a key | from L, bend the thumb in and straighten it again                  |
| Double click       | two quick thumb bends                                                    |
| Drag               | keep the thumb bent until `DRAG READY`, move the hand, straighten to drop |
| Right click        | from L, bend the index finger and straighten it again                    |
| Scroll             | index + middle together, thumb tucked; hold the hand above / below the start point |
| Pause / resume     | hold a fist ~1 s                                                         |
| On-screen keyboard | hold a shaka 🤙 (only thumb + pinky out) ~1 s                             |
| Rest               | any other pose — the cursor stays where it is                            |

**Ctrl+Alt+G** turns gesture control off and on instantly, so the real mouse can always take over.

## First start

1. **SmartScreen:** the exe is not code-signed, so Windows may show "Windows protected your
   PC" — click **More info** → **Run anyway**.
2. Raise your hand into the camera view, show the L pose and move.
3. Optional: tray → **Calibrate...** for a cursor speed that fits your hand.

Some antivirus programs flag one-file PyInstaller apps by mistake; the source is in this
repository and the build is reproducible with `python -m scripts.build`.

## Known limitations

- Without administrator rights AirTouch cannot click windows that run as administrator
  (a Windows restriction).
- The keyboard position is not remembered between starts.
- One hand at a time; very dim light or a hand partly out of the frame makes tracking unstable.

## Build from source

```powershell
py -3.13 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install -e .
python -m scripts.build
```
